# 照片与音乐资源

按用户明确要求，封面 `ziye-evening.jpg`、相册 `ziye-warm.jpg`、`ziye-daylight.jpg`、`ziye-cafe.jpg` 和用户提供的 `bgm.mp3` 纳入 Git。这些是压缩并清理元数据的网页版本，不是原始附件。`ziye-cafe.jpg` 来自最新提供的照片，仅裁去上下黑边，用于「万家灯火，偏偏看向你。」及其放大预览，不替换封面。其他媒体仍由 `.gitignore` 默认排除。

星光占位 SVG 仍保留，缺少照片时，源码页面与导出页面都使用占位图。公开仓库中的照片可以被他人下载和复制，请确认相关分享权限。

配乐为尹美莱（Yoon Mi-rae）、徐正权（Tiger JK）和 Bizzy 演唱的《Angel》。`bgm.mp3` 来自用户提供的文件，约 4 分 15 秒；当前仓库已使用 128 kbps 压缩版，本次排版调整保留现有文件，不再次转码。保留当前预加载与静音预播逻辑，正常点击、触摸或 Enter / 空格交互时取消静音并在必要时重试。BGM 循环播放，切到后台暂停，返回后尝试继续。所有音乐按钮、配乐卡片与本地选曲入口均已删除，不显示播放器或提示弹窗。

`experience/index.html` 中 `#background-music` 已设置 `data-src="assets/bgm.mp3"`。导出脚本将音源内嵌至离线 HTML，并同步至本机 `public/experience/`；这些生成文件默认不提交。照片与歌曲版权仍归原权利人，仓库不授予额外使用许可，公开发布前请确认分享与音源分发授权。
